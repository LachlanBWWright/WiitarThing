# Controller report fixtures

`reports.json` contains synthetic protocol packets, including report IDs and the
22-byte padding used by the Windows HID transport. These fixtures establish
parser behavior; they do not establish compatibility with physical controllers.

To add hardware recordings, preserve the original bytes and report boundaries.
Record the controller model, Bluetooth stack/adapter, build configuration, report
mode, capture source, and expected inputs in a separate fixture with provenance.
Remove device addresses and other identifiers. Include idle packets, presses and
releases, extension attach/detach, and failed negotiation replies. Never replace
captured packets with generated bytes while retaining a recorded label.
